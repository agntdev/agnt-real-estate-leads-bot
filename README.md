# Agnt Real Estate Leads Bot

Telegram bot that captures real-estate leads (name, phone, intent, note), confirms entries, notifies the owner, and provides an owner-only lead inbox.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
